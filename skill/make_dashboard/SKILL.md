# HR 이탈 위험 검토 화면

## 실행

```bash
python <스킬 폴더>/scripts/make_dashboard.py --result <퇴사위험_결과.xlsx> --data <동일 기준일 원본.xlsx> --out <출력 폴더> [--share]
```

결과만 있으면 원본 없이 생성할 수 있다. 원본이 다른 회사·기준일이면 중단한다. 결과가 없으면 `/predict_attrition`의 학습/현재 예측/진단 분기를 먼저 따른다. 예측 오류를 규칙 점수로 자동 대체하지 않는다.

완성한 dashboard.html을 읽고 아티팩트 또는 미리보기로 보여준다. 외부 리소스가 없는 단일 HTML이다.

## 화면과 읽는 법

- 직원 목록을 먼저 보여준다. 주요 근거는 실제 값·단위·기간·비교 기준이다.
- 조직·검색·위험 구간·유지 우선순위·상태 필터를 KPI, 직원 목록, 조직 요약, 신호, 근무 현황, 설문, 가설 탐색에 똑같이 적용한다.
- 전체 명부 비교 기준과 모델의 과거 검증 기록은 전체 범위임을 명시한다. 필터가 모델을 재학습하지 않는다.
- 퇴사위험 점수와 HR 지정 유지 우선순위는 별개다. 모델 점수도 보정된 퇴사 확률이 아니다.
- 담당자·확인 상태·다음 확인일·유지 우선순위는 브라우저에 저장된다. JSON 내보내기/가져오기로 옮길 수 있다. 다른 회사 기록은 거부하고 기존 기록 충돌은 덮어쓰지 않는다. 공동 편집 시스템이 아니다.
- H1~H9, V1~V9와 모델 성능은 기본 접힌 상세다.
- 원본이 없거나 선택 범위에 자료가 없으면 해당 패널은 이유를 표시한다.
- `--share`는 식별자를 가명으로 바꾼 별도 파일을 만든다. 가명은 기준일 간 안정적인 직원 ID가 아니므로 공유용 기록은 같은 기준일에서만 재사용한다.

성능 질문은 `evaluation.json`의 미래 기간 수치를 읽는다. 합성 데이터 결과를 실무 성능으로 말하지 않는다.

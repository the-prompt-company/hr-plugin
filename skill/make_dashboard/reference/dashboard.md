# 화면 계약

화면은 직원 목록 중심이며 가설·검증·모델 성능은 native details로 접혀 있다.

업무 패널은 동일한 visible() 집합을 사용한다. 조직 키는 본부와 팀의 복합 키다. 동명 팀을 합치지 않는다.
원본 근태·설문을 직원별로 담고 필터 뒤 집계하므로 직원 목록과 집계의 모집단이 같다.
월 중간 기준일은 완료된 이전 달까지 월별 근태를 사용한다.

신호 보드: 선택 평균, 전체 명부 평균, 실제 관측 인원. 값이 평균보다 높다는 이유로 위험 기여라고 표시하지 않는다.
직원 상세: 실제 값과 학습 중앙값(모델)/전체 평균(진단). 예측 주요 신호는 각 피처를 학습 중앙값으로 대체했을 때 점수 차이이며, 인과 효과나 합이 맞는 SHAP 값이 아니다.
추천 의향 0~10의 평균을 eNPS라고 부르지 않는다.

검증과 모델 성능은 과거 실행 전체 기록이다. 필터 대상 성능인 것처럼 재표시하지 않는다.
기록 키는 회사 식별자(없으면 회사명 해시)별 namespace를 쓴다. 같은 이름의 다른 회사에는 고유 company_id를 제공해야 한다.
JSON import는 스키마·회사·필드 값을 검사하고 충돌은 기존 기록을 보존한다. 새 기록 반영은 원자적으로 수행한다.
브라우저 저장 불가 시 경고하고 export 경로를 제공한다.

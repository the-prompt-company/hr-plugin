# HR 결과 해석 v0.5

- 진단 지수는 현재 모집단의 신호를 공개 규칙으로 합친 값이다. 미래 퇴사 확률이 아니다.
- 고정 모델의 점수도 보정된 퇴사 확률로 표시하지 않는다. 높음은 회사 전체 상위 K명, 주의는 다음 K명이다. 표시 필터는 이 구간을 재계산하지 않는다.
- 성능은 evaluation.json의 미래 기간별 Precision/Recall/Lift@K를 먼저 읽는다. AP, ROC-AUC, Brier와 구간별 예측/관측 비율은 보조 지표다. 단순 기준선과 같은 기간에서 비교한다.
- 모델 주요 근거는 해당 값을 학습 중앙값으로 대체했을 때 점수가 낮아지는 신호다. 실제 값·기간·단위를 함께 보여준다. 이 수치는 인과 효과도, 기여 합이 맞는 SHAP 값도 아니다.
- 평균보다 높음/낮음과 모델의 위험 방향을 혼동하지 않는다. 예측 모델 방향과 반대되는 고정 문구를 붙이지 않는다.
- 유지 우선순위는 HR이 핵심 직무·대체 난이도 등을 고려해 별도로 기록한다.
- 추천 의향 응답 평균(0~10)을 조직의 eNPS로 부르지 않는다.
- 병가·설문 미응답·나이·민감 속성은 개인 예측 피처에서 제외한다.

규칙 가중치의 단일 원천은 model.HEURISTIC_WEIGHTS이며 실제 적용 가중치는 metrics.json에 기록한다. 문서에 별도 가중치 복사본을 유지하지 않는다.

# 기간·유형을 반영하는 퇴사 라벨

필수 열: `employee_id`, `left_date`, `left_type`, `observed_until`.
`left(0/1)`만 있는 입력은 학습하지 않는다. 기존 left 값보다 실제 사건 일자·유형으로 만든 라벨을 사용한다.

- 대상 유형: `자발적 퇴사` 또는 `전체 퇴사`.
- 양성: 기준일 다음부터 지정한 N일 이내에 발생한 대상 퇴사.
- 음성: 해당 기간을 끝까지 관측했고 기간 내 퇴사가 없음.
- 관측 미완료: 제외. 나중에 사건이 관측됐더라도 기간 밖 미관측자를 0으로 만들지 않음.
- 자발적 퇴사 분석의 기간 내 비자발적·정년·계약 만료: 경쟁 사건으로 제외.
- 유형 불명: 자발적 분석에서 제외.
- 기준일 전에 퇴사: 기준일 모집단에서 제외.
- 날짜 오류·빈 관측 종료일·중복 사번: 차단.

자발적 유형 별칭: `자발적`, `자발적 퇴사`, `voluntary`.
다른 유형: `비자발적`, `비자발적 퇴사`, `involuntary`, `계약만료`, `계약 만료`, `정년`, `retirement`.
미퇴사자는 left_date와 left_type을 비운다. observed_until은 실제 추적 가능한 마지막 날짜다.
재입사자는 고용 에피소드별 식별자를 사용한다. 퇴사일이 잘못된 값을 날짜 변환으로 숨겨도 원래 오류를 보존하여 거부한다.

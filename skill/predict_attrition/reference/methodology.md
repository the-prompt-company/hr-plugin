# 분석 절차 v0.5

질문(회사·퇴사 유형·기간·모집단·K)을 먼저 정의한다. 예측과 진단을 분리한다.

1. 원본 기준일·사번·날짜를 검사한다. 원본 변환 오류를 보존하고 미래/날짜 불명 이력은 피처에서 실제 제외한다. recorded_at이 있으면 당시 가용성도 검사한다. 월중 기준일의 월 집계는 이전 완료 월까지 사용한다.
2. 과거 스냅샷의 사건 일자·유형·관측 종료일로 라벨을 만든다. 세부 계약은 labels.md.
3. 학습/검증/미래 평가를 시간으로 분리하고 라벨 기간 경계를 제거한다. 후보 비교와 최종 평가를 분리한다. training.md 참조.
4. 고정 모델을 현재 직원에 적용한다. 현재 라벨은 학습하지 않는다. 회사·질문·기간·기준일·필수 피처가 맞지 않으면 중단한다.
5. 위험 점수와 유지 우선순위를 분리한다. 직원별 근거는 실제 값과 비교 기준으로 설명한다. 대화가 가중치·원인·성능을 만들지 않는다.
6. 모델 ID·스펙·입력 해시·실행 기록을 저장한다. 표시 필터는 재학습하지 않는다.

V1~V8은 데이터·계산 검사이며 예측 정확도를 보장하지 않는다. V9는 고정 모델이 있으면 미래 평가를 참조하고, 합성 데이터/기준선 미개선은 경고다. 모델이 없는 진단은 예측 성능을 주장하지 않는다.

원본 셀별 근거 연결, 확률 보정, 조치의 인과 효과 추정, 공동 편집은 현재 구현 범위가 아니다.
